# 나의 미래 직업 번역기

'생성형 AI로 그리는 나의 미래 직업' 수업에서 학생들이 쓰는 한국어 → 영어 번역기예요.

- 학생용 주소: https://dlrka0131-cyber.github.io/translator/
- 나이 · 성별 · 미래 직업 · 하고 있는 일 · 배경을 채우면 그림 AI에 넣을 문장을 만들어 영어로 바꿔 줘요.
- 구글 번역이 막히면 크롬 안의 번역 AI(비상 번역), 예비 서버 순으로 자동으로 넘어가요.

## 수업 전 준비
1. 학생 컴퓨터에서 크롬으로 주소를 열어요.
2. 오른쪽 위가 '⬇️ 비상 번역 준비하기'면 한 번 눌러 '✅ 비상 번역 준비됨'으로 바꿔 둬요.
3. 문장을 하나 번역해 보고, 번역 칸 아래에 '번역: 구글 번역'이 뜨는지 확인해요.
